    Chapter 10 Text metadata (profileDesc)

    profileDesc to record the text-specific metadata: correspContext, abstract, textClass and langUsage

    <profileDesc>
  <correspDesc>
    <correspContext/>
  </correspDesc>
  <abstract/>
  <textClass/>
  <langUsage/>
</profileDesc>

    10.1 Correspondence with other resources (correspContext)

    The correspContext element is used to specify the editorial context of the text. Editors may explicitly specify which text is to logically follow in the edition, and which to precede it.

    Optionally, any number of other pointers, deemed relevant by the editors, may be provided. Such references may link to related individuals or places, etc.

    <correspDesc>
  <correspContext>
    <ref type="prev" target="#zs0216">17 lipca</ref>
    <ref type="next" target="#zs0218">19 lipca</ref>
    <listRef type="related">
      <ref target="BTO1130">Fryderyk z Utrechtu</ref>
    </listRef>
  </correspContext>
</correspDesc>

    10.2 Classification

    The textClass section of the TEI header is used to provide formal classification for various characteristics of the text. These can regard the content, for example the genre or period, the form (e.g. manuscript or print) or even aspects of the editorial workflow (e.g. status, in the example below recording completed stages of preparation).

    Regardless of the purpose of the classification, the classification schemes and values used MUST be defined in a project taxonomy (or multiple taxonomies), so the references can be resolved.

    These taxonomies can be found in registers collection in the dataset.

    <textClass>
  <catRef scheme="#genre" target="#vita"/>
  <catRef scheme="#corpus" target="#zs"/>
  <catRef scheme="#gender" target="#m"/>
  <catRef scheme="#form" target="#print"/>
  <catRef scheme="#status" target="#apparatus #bibl #commentary"/>
  <catRef scheme="#period" target="#c9"/>
</textClass>

    10.3 Language use

    Languages used in the source text should be recorded 

    <langUsage>
  <language ident="pl">polski</language>
  <language ident="la">łaciński</language>
</langUsage>

    10.4 Sources

    Text's sourceDesc is linking to a corresponding entry in the file describing the entire collection (corpus). The referenced file must list all the witnesses referenced in the readings.

    The witness/@xml:id identifier is used as a witness siglum (reference) for any apparatus readings attested by that witness

    <sourceDesc xml:id="zs-sourceDesc">
  <listWit xml:id="zs-wit">
    <witness xml:id="ZS1579">1579</witness>
    <witness xml:id="ZS1585">1585</witness>
    <witness xml:id="ZS1592">1592</witness>
    <witness xml:id="ZS1598">1598</witness>
    <witness xml:id="ZS1601">1601</witness>
    <witness xml:id="ZS1603">1603</witness>
    <witness xml:id="ZS1610">1610</witness>
  </listWit>
</sourceDesc>
