    Chapter 2 Identifiers and referencing mechanisms

    Identifiers, represented as @xml:id attributes on appropriate elements follow a consistent naming scheme across the edition material, slightly distinct for transcriptions and transliterations.

    Identifiers are defined exactly once across the dataset, where they occur as a value of @xml:id attribute on an XML element

    Identifiers may be used multiple times when they are referenced from another element. This may be done via a number of pointing attributes, such as @corresp, @synch, etc. Each of these attributes has a specific function across the dataset.

    2.1 Registers

    References for people, places, bibliography, glosses and analytical features can be resolved against appropriate registers, all stored in registers subcollection as TEI XML.

    The taxonomy.xml contains metadata classification schemes.

    All other registers and authority files are imported from external system of the Jagiellonian University called Bytownia.

    • persons.xml: people
    • glossary.xml: terms
    • bibliography.xml: references
    • taxonomy.xml: classifications and taxonomies
