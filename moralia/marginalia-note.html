    Chapter 5 Marginalia (note)

    Marginalia, representing secondary headings (arguments) or references to other works, are encoded with note with @place set to margin. Attribute @type should be set to ref for intertextual references.

    In rare cases where the marginale is supplied by the editor, it will be explicitly marked with @resp set to editor.

    <note place="margin">Pijaństwo bez wina</note>

    note may also be used to encode editorial commentary, see the corresponding chapter
