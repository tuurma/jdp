    Chapter 4 Formal structure of the poem

    Every morale is represented as a single div element. It comprises of an obligatory head element, followed by one or more of lg (strophes). Structural, top level elements (direct children) of the division may also include marginal notes.

    Selected elements of the physical structure of the document, namely page beginnings may also occur.

    The example below shows a simplified example, illustrating the top-level components of a division.

    <div xml:id="I.1" n="1" synch="#I.1">
  <pb facs="#f_8r" xml:id="pb.I.1.1" synch="#pb.I.1.1"/>
  <head xml:id="I.1.title" synch="#I.1.title" facs="#f_8r.zone-2">
Citra vinum temulentia<anchor corresp="#I.1.c.1"/></head>
  <note place="margin" type="argument">Pijaństwo bez wina</note>
  <lg><l xml:id="I.1.1" n="1" synch="#I.1.1" facs="#f_8r.zone-3">Niechaj się nikt nie myli, żeby tylko winem</l><l xml:id="I.1.2" n="2" synch="#I.1.2" facs="#f_8r.zone-4">Abo więc trunkiem ludzie upijali inem;</l>
...
</lg>
</div>

    4.1 Poem identification, classification and alignment

    The div element MUST carry the following attributes:

    • @xml:id: an identifier (obligatory)
    • @synch: synchronization key, same as the identifier of morale transcription
    • @n: ordinal (a number)

    The @synch attribute is used to identify aligned structures across the text versions. Principally, this mechanism is used to align transcription and transliteration, but it may be extended to various translations and other text versions.

    4.2 Poem title (head)

    Each morale MUST have a head providing its title. Where such a heading doesn't appear in the source text, it MUST be supplied and explicitly marked up with supplied element.

    <head>Citra vinum temulentia</head>

    4.3 Line groups and verse lines

    All verse lines l MUST be grouped into strophes (lg).

    Each verse line MUST have @xml:id, @synch and @n attributes, lines in transcription MUST additionally have the @facs attribute.

    <lg><l xml:id="I.1.1" n="1" synch="#I.1.1" facs="#f_8r.zone-3">Niechaj się nikt nie myli, żeby tylko winem</l><l xml:id="I.1.2" n="2" synch="#I.1.2" facs="#f_8r.zone-4">Abo więc trunkiem ludzie upijali inem;</l><l xml:id="I.1.3" n="3" synch="#I.1.3" facs="#f_8r.zone-5">Żadnym masłokiem, który dla szaleństwa piją,</l><l xml:id="I.1.4" n="4" synch="#I.1.4" facs="#f_8r.zone-6">Ani tak drwią gorzałką jako opiniją.</l>
...
</lg>

    4.4 Marginalia (note)

    Marginalia, representing secondary headings (arguments) or references to other works, are encoded with note with @place set to margin. Attribute @type should be set to ref for intertextual references, and argument for secondary headings. All other marginalia types should bear the other value for this attribute.

    <note place="margin" type="argument">Pijaństwo bez wina</note>

    note may also be used to encode editorial commentary, see the corresponding chapter
