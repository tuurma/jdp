    <catRef>

    category reference

    specifies one or more defined categories within some taxonomy or text typology.

    Module headerHD43

    Attributes

    Global and inherited attributes:
    att.global @xml:id@n@xml:lang@xml:base@xml:space

    @schemeidentifies the classification scheme within which the set of categories concerned is defined, for example by a taxonomy element, or by some other resource.

    Note

    The @scheme attribute needs to be supplied only if more than one taxonomy has been declared.

    Example

    <catRef scheme="#myTopics" target="#news #prov #sales2"/>
<taxonomy xml:id="myTopics">
  <category xml:id="news">
    <catDesc>Newspapers</catDesc>
  </category>
  <category xml:id="prov">
    <catDesc>Provincial</catDesc>
  </category>
  <category xml:id="sales2">
    <catDesc>Low to average annual sales</catDesc>
  </category>
</taxonomy>
