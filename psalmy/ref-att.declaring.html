    att.declaring

    provides attributes for elements which may be independently associated with a particular declarable element within the header, thus overriding the inherited default for that element.

    Module tei

    Attributes

    @declsidentifies one or more declarable elements within the header, which are understood to apply to the element bearing this attribute and its content.
