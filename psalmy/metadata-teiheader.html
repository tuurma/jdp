    Chapter 9 Metadata (teiHeader)

    • titleStmtto record the psalter title and contributors
    • sourceDesc from the header module to record information about the source document (or documents where multiple witnesses were used); there must be as many nested bibl elements as are the witnesses for a given text version
    • profileDesc from the header module to record the most important metadata: abstract, textClass and langUsage

    NB: bibl/@xml:id identifier is used as a witness siglum (reference) for any apparatus entries relevant to that witness

    <sourceDesc>
  <bibl xml:id="PF1395">
    <title>Psałterz floriański</title>
    <date when="1395">ca 1395-ca 1405</date>
    <ref target="https://polona.pl/preview/43713d40-72bd-439c-b7ce-300541ade137">Biblioteka Narodowa <idno type="BN">Rps 8002 III</idno></ref>
  </bibl>
</sourceDesc>
