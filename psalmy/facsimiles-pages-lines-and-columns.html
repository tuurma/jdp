    Chapter 5 Facsimiles, pages, lines, and columns

    Beginnings of each page, column and line in the primary source need to be encoded with pb, cb and lb elements, respectively.

    5.1 Pages

    Page beginning markers must be placed as a first node in a div, or wherever they occurr in the source text.

    Page beginnings require @facs, @n and @xml:id attributes.

    <div type="psalm" n="1" xml:id="PF-001" corresp="commentary-ps-001" synch="ps-001" ana="#wisdom"><pb facs="334664cd-855a-4ffd-b87b-757d5c6841f6" n="3r" xml:id="PF-pb-001"/><cb n="a"/><head>Psalm 1</head>
...
</div>

    5.2 Facsimiles

    Default IIIF service is Polona, since most of the Psalter editions are available in facsimile from there.

    The value of @facs should be the facsimile identifier from Polona, as in the example above. Facsimiles from the Jagiellonian IIIF service must use the hub: prefix and a relative path to the image resource.

    <pb xml:id="PK-pb-013" facs="hub:PF/PF_page_013.tif" n="1"/>
<head>Pſalm Dawidow 1</head>

    5.3 Lines

    Line beginnings should be marked just before the text occurring on the line in question. The lb element should be kept within the parent element of the text starting on that line, usually ab.

    Where line beginning occurs within a word, it should be encoded in the original (not the regularized) form and additionally marked with a @break attribute with a value no.

    <choice>
  <orig>cze<lb break="no"/>køcych</orig>
  <reg>...</reg>
</choice>

    5.4 Columns

    If the primary source is divided into columns, these may be marked with cb.

    The first column beginning on the page directly follows the page beginning marker. Other column beginning markers are placed as they occur, but where possible are kept at the ab level.

    Where column starts within a word, it should be marked only in the original form, not the regularized. The line beginning marker naturally then follows the column beginning.

    <ab type="verse" n="2" xml:id="PF-001-02" synch="ps-001-02"><lb/> ... meditabitur die ac nocte
<cb n="b"/><lb/>Ale w zacone
...
</ab>
